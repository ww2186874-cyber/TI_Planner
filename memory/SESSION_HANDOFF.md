- `1.3.0-beta.10` 已将每个工程固定为创建时选择的一个芯片型号和一个封装；顶部切换控件已删除。
- 新建工程窗口支持空白工程和动态板卡模板。空白工程选择型号/封装，模板自动锁定目标；首次启动没有工程时不能关闭新建窗口。
