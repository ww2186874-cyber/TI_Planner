# 长期决策

## 2026-07-14：固定工作区和发布方式

- `<USER_HOME>\Desktop\MSPM0` 是唯一正式开发工作区。
- 使用 Electron 便携版，优先保证目标电脑无需 Node、WebView2或安装运行库。
- `outputs/` 是候选构建区，`releases/vX.Y.Z/` 是不可覆盖的正式归档。
- Git 记录源码、脚本、文档、发布说明和哈希，不记录依赖缓存及大型 EXE/HTML。

## 2026-07-14：预览优先

- 普通界面和逻辑先生成 HTML 预览。
- Electron 专属功能使用 `run-dev.cmd` 预览。
- 用户确认后才提升版本并生成正式便携 EXE，避免每个小调整都等待压缩。

## 2026-07-14：数据兼容

- 保持 `appId`、应用名称和 `app://mspm0/` 稳定。
- 两颗芯片、不同封装和视图状态独立保存。
- 保存结构变化必须提升版本并迁移旧数据。

## 2026-07-14：产品范围

- 当前只做引脚规划，不生成初始化代码，也不验证完整电气设计。
- 主要面向桌面端，不以手机布局为当前目标。
- 图标和品牌采用原创、无厂商文字的芯片图形，降低官方关联误解。

## 2026-07-14：候选版和快速启动版

- 新功能先发布 `X.Y.Z-beta.N` 候选源码，不创建正式版本标签。
- 候选确认优先使用离线 HTML 和快速启动文件夹版，减少反复压缩单文件 EXE 的等待。
- 正式发布仍同时保留单文件便携版、文件夹版和离线 HTML。
- 三种交付形式统一归档在 `releases/vX.Y.Z/`：EXE 和 HTML 放在版本目录根部，快速启动版使用带版本号的 `*-Folder/` 子目录，并分别生成文件哈希清单。

## 2026-07-14：工程与合规

- 一个软件工作区可以保存多个相互隔离的引脚工程，旧版单工程数据迁移为“默认工程”。
- 软件明确标注“非 TI 官方工具”，发行物保留作者、数据来源、免费学习版许可和第三方声明。
- 对外作者署名统一使用“天津职业技术师范大学 电子创新协会”，不再使用个人或班级署名。
- QEI 完整性只要求 C0/A 相和 C1/B 相，IDX/Z 索引保持可选。

## 2026-07-19：VQFN 封装数据复用边界

- MSPM0G3507 和 MSPM0G3519 均支持官方 RHB-32、RGZ-48 VQFN 封装。
- 同一芯片的 RGZ-48 与 PT-48 物理脚号和逻辑引脚一一对应，可以复用完整引脚数据，并由自动校验保证持续一致。
- 两颗芯片的 RHB-32 物理脚序相同，但 IOMUX 和外设功能不同；只复用物理脚骨架，完整功能必须从同一芯片的 PT 数据生成，不得跨芯片复制。
- VQFN 裸露散热焊盘没有独立物理引脚号，不作为第 33 或第 49 个规划引脚。

## 2026-07-19：新工程保留官方调试与复位默认功能

- 新建工程的每种芯片和封装默认安排 `SWDIO`、`SWCLK`、`NRST`，物理脚号由同芯片同封装的官方功能数据查找，不跨芯片硬编码复制。
- 官方默认只在创建全新工程时写入；加载已有工作区、导入旧工程和用户清空封装时不得自动补回，避免覆盖用户规划。
- 默认项不是锁定脚：SWD 引脚可改作其官方支持的 GPIO或复用功能，NRST 可清除；只有官方数据包含 `WAKE` 的 MSPM0G3519 才提供 NRST/WAKE切换。
- 下载调试功能使用独立 Debug 分类和颜色，NRST/WAKE 使用 System 分类和颜色，电源/地继续保持固定且不可编辑。
