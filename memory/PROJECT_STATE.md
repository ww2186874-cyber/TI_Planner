## 产品范围

- 支持 `MSPM0G3519` 与 `MSPM0G3507`。3519 支持 RHB-32、RGZ-48、PT-48、PM-64、PN-80、PZ-100；3507 支持 RHB-32、RGZ-48、PT-48、PM-64。
- 一个工程在创建时固定一个芯片型号和封装；支持空白目标与锁定目标的天猛星 PM-64 板卡模板。没有工程时必须先完成新建工程。
- 板卡模板提供固定连接、可切换资源、GPIO 排针、电气限制和 SPI1 共享总线展示；关闭资源时保留用户文字与仍由其他资源使用的共享信号。
- 外设实例信号显示在列表右侧的相邻详情栏，打开时压缩并适配芯片画布，不覆盖画布。
- 顶部工程与操作保持单排；工程选择组在宽屏适度右移，窄窗口自动收回偏移。
- Windows x64 Electron 桌面优先，固定夜间界面，打印报告保持白底。
