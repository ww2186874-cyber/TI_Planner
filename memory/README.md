# 项目长期记忆

这里保存跨 Codex 任务仍然有价值的信息。新任务必须先读，结束任务时按需更新。

## 文件职责

- `PROJECT_STATE.md`：当前版本、支持范围、构建状态和最近发布。
- `DECISIONS.md`：已经确定的架构、产品和工作流决策，以及决策原因。
- `LESSONS.md`：遇到过的问题、根因、解决办法和预防措施。
- `KNOWN_ISSUES.md`：尚未解决或属于产品取舍的问题。
- `SESSION_HANDOFF.md`：上一任务留下的未完成事项和下一步。

## 记录原则

- 只写可验证、可复用、以后会影响开发的事实。
- 每条尽量包含日期、背景、结论和验证方式。
- 不复制完整对话，不记录一次性命令输出，不保存密码、令牌和个人数据。
- 已失效内容应修改或标记为失效，不要让相互冲突的结论长期并存。
- Git 历史是记忆的依据；正式版本以 `releases/` 和标签为准。
