# 工作区整洁规则

## 根目录只保留长期入口

根目录允许出现源码目录、文档目录、构建入口、版本记录和项目配置。临时截图、测试 JSON、一次性脚本和调试日志统一放入 `.tmp/`。

## 生成内容的归属

- `outputs/`：候选 HTML 和 EXE，可以被同版本重建覆盖。
- `releases/`：正式版本，不得覆盖或自动删除。
- `desktop/dist/`：Electron 打包中间产物。
- `desktop/app/index.html`：由网页构建自动复制。
- `.cache/`、`.pnpm-store/`、`desktop/node_modules/`：长期保留的依赖和缓存。

## 任务结束检查

1. 运行 `workspace-check.cmd`。
2. 检查 `git status`，确认没有来源不明的文件。
3. 更新 `memory/` 中真正需要跨任务保留的信息。
4. 完成的源码和文档提交 Git；正式发布创建版本标签。
5. 不为追求“干净”删除缓存、历史版本或用户文件。

## 删除原则

- 自动体检只报告，不删除。
- 仅删除本任务明确生成、已经验证不再需要的临时文件。
- 递归删除前必须确认目标绝对路径位于 `.tmp/` 或明确的测试目录。
- 发现不认识的文件时保留并询问，不猜测其来源。
