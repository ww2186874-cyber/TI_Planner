# 工作区整洁规则

本文只规定文件归属和清理边界；任务门禁见 `AGENTS.md`，构建流程见 `docs/DEVELOPMENT.md`。

## 文件归属

| 位置 | 内容 | 是否可自动覆盖 |
|---|---|---|
| 项目根目录 | 长期入口、配置、版本记录 | 否 |
| `.tmp/` | 临时截图、测试数据、日志和一次性脚本 | 仅限本任务确认生成的内容 |
| `outputs/` | 当前候选 HTML、EXE 和文件夹版 | 是，同一候选可重建 |
| `desktop/app/`、`desktop/dist/` | 构建生成内容 | 是，由脚本管理 |
| `releases/vX.Y.Z/` | 正式历史归档；含 `REJECTED.md` 时仅为未发布审计记录 | 否 |
| `.cache/`、`.pnpm-store/`、`desktop/node_modules/` | 长期依赖与构建缓存 | 否，除非确认损坏 |

## 整理原则

- `workspace-check.cmd` 只报告，不删除。
- 不为追求 Git 干净而清理忽略目录、依赖缓存、正式归档或用户文件。
- 只有能够确认由当前任务生成且不再需要的临时文件可以直接删除。
- 递归删除前核对绝对路径，目标必须位于 `.tmp/` 或明确的测试目录。
- 来源不明的根目录项目先保留并报告；需要删除时取得用户确认。
- 生成文件不进入 Git；发现被跟踪时先查明历史和脚本，不直接移除正式产物。
