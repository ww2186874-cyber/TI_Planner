# 正式版本归档

每个正式版本保存在独立的 `vX.Y.Z` 目录中。旧版本不得被自动覆盖或删除。正式归档必须包含发布说明和 SHA-256 清单，且拥有同名 Git 标签。

正式标签创建前验收失败的构建也不得覆盖或伪装成正式版本。为保留审计记录，这类目录必须包含 `REJECTED.md`，发布说明首部必须明确禁止分发，并且不得创建同名 Git 标签；`workspace-check.cmd` 会把它排除在正式版本之外。

EXE 和 HTML 文件不写入 Git 历史，但会保留在本工作区；Git 会记录发布说明、SHA-256、拒绝标记和正式源码标签。发布脚本禁止并行运行，并通过同卷临时目录完成后再原子落盘。
